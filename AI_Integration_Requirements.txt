# YÊU CẦU TÍCH HỢP TỪ TEAM DEV GỬI TEAM AI
Dự án: MindX Game Asset Generator
Hạng mục: Bổ sung siêu dữ liệu (Metadata) cho tính năng Tạo Sprite Sheet / Animation.

Kính gửi team AI,

Để chức năng "Cắt Sprite Sheet (Cắt Gạch/Animation) Thủ Công và Tự Động" trên giao diện (Frontend) hoạt động chính xác, team Dev cần phía AI khi trả về kết quả hình ảnh (dạng Base64 hoặc URL), vui lòng trả kèm một Object JSON chứa Metadata của cấu trúc ảnh đó.

## Yêu Cầu Cụ Thể
Khi người dùng request tạo một "Sprite Sheet" hoặc "Tileset" (Ví dụ: 1 chuỗi hành động chạy của nhân vật, hoặc 1 set gạch), kết quả từ API của team AI cần trả về theo định dạng JSON chuẩn như sau:

```json
{
  "image": "data:image/png;base64,...",
  "metadata": {
    "total_frames": 8,
    "layout_format": "horizontal", 
    "frame_width": 64,
    "frame_height": 64,
    "columns": 8,
    "rows": 1
  }
}
```

## Giải thích các tham số (BẮT BUỘC):
1. total_frames (int): Tổng số khung hình (frames) có trong tấm ảnh lớn. Ví dụ: Nếu ảnh có 8 khung hình, trả về 8.
2. layout_format (string): Cách AI bố trí các frame trên ảnh lớn.
   - Trả về "horizontal" nếu tất cả frame xếp thành 1 hàng ngang.
   - Trả về "vertical" nếu tất cả frame xếp thành 1 hàng dọc.
   - Trả về "grid" nếu các frame xếp thành nhiều hàng, nhiều cột (Lưới).
3. frame_width (int) & frame_height (int): Kích thước (chiều rộng x chiều cao) bằng pixel của MỖI KHUNG HÌNH (không phải kích thước của cả tấm ảnh to). 
   - Ví dụ: Ảnh to là 512x64, có 8 frame ngang -> frame_width = 64, frame_height = 64.
4. columns (int) & rows (int): Số lượng cột và hàng trên tấm ảnh lớn. 
   - Ví dụ: layout ngang 8 hình thì columns = 8, rows = 1.

## Lý do cần thiết:
Hiện tại, khi team AI chỉ trả về một bức ảnh to (Image) duy nhất, team Dev ở Frontend/Backend phải cho người dùng TỰ ĐIỀN THỦ CÔNG số lượng khung hình và TỰ ĐO kích thước để cắt (Slicing/Crop). Nếu có Metadata từ AI trả về, hệ thống sẽ tự động vẽ lưới cắt (Grid) chuẩn xác 100% và chạy được Preview Animation mượt mà ngay lập tức mà không bắt User phải mò mẫm.
